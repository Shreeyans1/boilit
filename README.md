boilit

A tool that turns a daily calorie goal into meal plan options built from what the Purdue dining halls are serving.

Project goal

College students often skip meals or guess at what to eat to hit a calorie goal. boilit lets a user set a daily calorie goal and some other specifications, then creates meal plan options from the foods that are available. The user picks the option they prefer for each meal. If the goal isn't reached, the user can add the leftover to the next day's goal and get a reminder at a time they choose.

MVP scope

The smallest version that proves the idea:

Enter a daily calorie target
Read foods from one saved menu file (no live fetching yet)
Use typical calorie values per dish, since the menu data has no calories
Generate one meal plan that fits the target
Display the plan

Not in the MVP: user accounts and live fetching from the HFS menu link.

Future plans

Next up after the MVP works:

Specifications, such as diet filters
Multiple meal plan options per meal
Picking an option for each meal
Tracking progress toward the daily goal
Tech stack
